# Kurd Agent

ئەجێنتێکی تایبەت بەخۆ، کوردی‌ئامادە و local-first. ئەم وەشانە لەگەڵ Ollama، دابەزاندنی GGUF لە Hugging Face، و پەیوەندیی خوێندنەوەی GitHub کار دەکات؛ مۆدێلی local لە دوای داگرتن ئۆفلاین کار دەکات.

> **دۆخی پڕۆژە:** ئەمە وەشانێکی سەرەتاییە، نەک forkێکی تەواوی Hermes Agent. گفتوگۆی خۆجێیی، داگرتنی GGUF لە Hugging Face بۆ Ollama، و سێ ئامرازی خوێندنەوەی GitHub بۆ agent ـەکەی تێدایە. memory ـی درێژخایەن، ویرایش/commitکردنی ڕێپۆ، automation، MCP و پەیوەندیی Google/Notion لەم وەشانەدا چالاک نین. ئەم repository ـە بەتاڵ بوو، بۆیە بناغەیەکی بچووک و تاقیکراوەی خۆجێیی دروست کراوە.

## دەستپێکردن

پێویستی بە Python 3.10+ هەیە؛ هیچ packageێکی سێیەم بەکارناهێنرێت. پڕۆژەکە هەروەها Android WebView wrapperێکی APK-ready هەیە؛ بەڵام APK ـەکە خۆی model weights یان inference engine ـی Android ناگرێتەوە. وردەکارییەکانی Android لە [`android/README.md`](android/README.md) بخوێنەوە.

```bash
python3 server.py
```

پاشان `http://localhost:8000` بکەرەوە. بۆ دەستپێکردنی سنووردار بە ئامێری خۆت (باشترە بۆ بەکارهێنانی تایبەتی):

```bash
HOST=127.0.0.1 python3 server.py
```

بۆ live preview ـی Arena، سێرڤەر بە بنەڕەت لەسەر `0.0.0.0:8000` گوێ دەگرێت. بۆ بەکارهێنانی خۆجێیی لە تۆڕی تایبەتی خۆت، `HOST=127.0.0.1` دابنێ؛ ئەم app ـە بۆ بەرهەمهێنانی ئینتەرنێتی بەبێ authentication دیزاین نەکراوە. تێبینی: live preview ـی Arena لە sandboxێکی دوور کار دەکات و ناتوانێت Ollama ـی ناو کۆمپیوتەری تۆ ببینێت؛ بۆ چاتی ئۆفلاین، ئەم app ـە لەسەر هەمان ئامێر لەگەڵ Ollama ڕابکە.

## مۆدێلی خۆجێیی و ئۆفلاین

1. [Ollama](https://ollama.com/) دابەزێنە و دایمەزرێنە.
2. مۆدێلێک ڕابکێشە؛ بۆ نموونە `ollama pull qwen2.5:7b`.
3. Ollama بە شێوەی بنەڕەتی لە `http://127.0.0.1:11434` کار دەکات.
4. Kurd Agent بکەرەوە، بچۆ بۆ **ڕێکخستن**، مۆدێلەکە هەڵبژێرە و پاشەکەوتی بکە.

تێبینی: بۆ یەکەم جار دابەزاندنی Ollama و مۆدێل، ئینتەرنێت پێویستە؛ دوای ئەوە چات لەسەر مۆدێلی local دەتوانێت ئۆفلاین کار بکات. خێرایی و توانای مۆدێل بە RAM/VRAM و ئامێرەکەتەوە بەستراوە. بەکارهێنانی cloud provider لە تەواو offline جیاوازە و دەتوانێت کرێی API هەبێت.

## Hugging Face

لە **ڕێکخستن → مۆدێلی ئۆفلاین لە Hugging Face** ناوی مۆدێل بگەڕێ و ڕێپۆی GGUF هەڵبژێرە، quantization دیاری بکە (بۆ نموونە `Q4_K_M`) و دایبەزێنە. پشتەوە Ollama مۆدێلەکە لە Hub ـی Hugging Face دەهێنێتە ناو library ـی خۆی. گەڕان/داگرتن ئینتەرنێت دەوێت؛ دواتر چات local ـە. قەبارەی مۆدێل دەتوانێت چەند GB بێت و ئامێری لاوازدا خاو دەبێت. ئەم flow ـە GGUF ـی گشتی دەخوازێت؛ repo ـی gated/تایبەت tokenێکی HF و ڕێکخستنی زیاتر دەوێت.

## GitHub

لە پەڕەی **پەیوەندییەکان** tokenێکی GitHub داخل بکە بۆ پەیوەستبوون. Agent دەتوانێت لیستی ڕێپۆکانت ببینێت، لە ڕێپۆی گشتی بگەڕێت و metadata ـی ڕێپۆ بخوێنێتەوە؛ بۆ ئەمانە هیچ write scopeێک پێویست نییە. Token ـەکە لە فایلێکی تایبەتی `~/.kurd-agent/secrets.json` (یان `%USERPROFILE%\\.kurd-agent` لە Windows) هەڵدەگیرێت؛ لە Android ـدا لە private storage ـی app ـەکەدا دەمێنێتەوە. دەتوانیت هەرکاتێک جیاکردنەوەی بکەیت.

ئامرازەکانی GitHub تەنها **read-only** ـن؛ Agent ناتوانێت commit/push بکات یان فایل بگۆڕێت. پەیوەندییەکانی تر لە ڕێگەی MCP وەک قۆناغی داهاتوو دانراون و هێشتا چالاک نین.

## مۆدێلی تر

لە **ڕێکخستن**، `OpenAI-compatible` هەڵبژێرە و URL ـی API بنووسە. بۆ نموونە LM Studio زۆرجار `http://127.0.0.1:1234/v1` بەکاردەهێنێت. API key بۆ endpoint ـەکانی cloud ئیختیارییە؛ بە شێوەی نهێنی لە ئامێرەکەت پاشەکەوت دەکرێت. بۆ پاراستنی نهێنییەکان API key زیاد مەکە بۆ hostێکی نائاشنا.

## داتا و نهێنی

- Python backend لەسەر ئامێری خۆت دەچێت؛ پەیامەکان بۆ مۆدێلی local نانێردرێنە دەرەوە.
- ئەگەر cloud API هەڵبژێریت، پەیامەکان بۆ ئەو API ـە دەنێردرێن.
- ڕێکخستن و token ـی GitHub لە `~/.kurd-agent/` هەڵدەگیرێن. چاتەکان لەم MVP ـەدا دوای نوێکردنەوەی پەڕە هەڵناگیرێن.
- لەم جێبەجێکردنەدا پەیوەندیی بەرنامەکانی تر تەنها پلانە؛ زانیاریی هەژمارەکانیان داوا ناکرێت.
